# Бот для записи клиентов

Клиент пишет боту в Telegram, выбирает услугу, день и время. Мастеру приходит уведомление, клиенту — напоминание накануне и за 2 часа.

## Как запустить (5 минут)

1. В Telegram откройте @BotFather, отправьте `/newbot`, придумайте имя. Он выдаст **токен** — скопируйте его.
2. Скопируйте файл `.env.example` в `.env` и вставьте токен в `BOT_TOKEN`.
3. Установите и запустите:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
4. Напишите своему боту `/id` — он ответит вашим Telegram ID. Вставьте его в `MASTER_ID` в `.env` и перезапустите бота. Теперь уведомления о записях приходят вам.

## Что настраивать под мастера

Всё в файле `config.py`: название, услуги и цены, рабочие часы, выходные. Код трогать не нужно.

## Команды мастера

- `/today` — записи на сегодня
- `/week` — записи на 7 дней

## Запуск на Railway

1. Загрузите папку в GitHub-репозиторий и подключите его в Railway.
2. В Variables добавьте `BOT_TOKEN` и `MASTER_ID`.
3. Важно: добавьте Volume (например, `/data`) и поставьте `DB_PATH=/data/bookings.db`, иначе записи пропадут при перезапуске.

## Как продавать

Для каждого нового мастера делается своя копия бота: свой токен и свой `config.py`.
